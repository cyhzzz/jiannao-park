# 增量迭代流程（incremental）

小步快跑，每次只动一块，验证后再合。

## 适用

- 文案微调、难度参数调整、样式微调、单个游戏的小优化。

## 流程

1. 读相关文件（先读后写）。
2. 最小改动，不顺手重构无关代码。
3. 出包验证（即便只改文案也建议过一遍，确认 `www/` 同步正确）。
4. 规则文件若变，跑 `check_rule_architecture.py` PASS。
5. 提交小 PR，勾选 Validation 清单。

## 注意

- 文案调整须保持长辈友好、正向鼓励（红线 RL-03 / Standard）。
- 不要为「顺手」同时改多个游戏逻辑，保持 diff 可评审。
